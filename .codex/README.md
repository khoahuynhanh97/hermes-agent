# Repository Codex Rules

This directory contains short repository-level activation rules for Codex. The
root `AGENTS.md` remains the automatically loaded instruction entrypoint.

For Hermes Personal or Product Video architecture work, read:

- [`rules/hermes-personal-architecture.md`](rules/hermes-personal-architecture.md)

Detailed reusable guidance lives in `.agents/skills/`. The `.codex` rule selects
the required skill; it does not duplicate the skill content.
